# Movie Watchlist Manager (MERN)

A full-stack Movie Watchlist Manager built with React + Vite, Express, Mongoose, and MongoDB Atlas.

## Requirements
- Node.js 18+
- npm
- MongoDB Atlas connection string

## Setup

### 1. Configure backend environment
Open `backend/.env` and replace the example `MONGO_URI` with your MongoDB Atlas connection string. The `.env` file is included as requested, but contains a placeholder, not working credentials. Never commit real passwords or production secrets.

### 2. Install dependencies
Open a terminal in the project root:

```bash
cd backend
npm install
cd ../frontend
npm install
```

### 3. Start the app
Terminal 1:
```bash
cd backend
npm run dev
```

Terminal 2:
```bash
cd frontend
npm run dev
```

Open the URL printed by Vite (normally http://localhost:5173).

## API list

All responses use `{ "success": boolean, "message": string, "data": ... }`.

- `GET /api/health` — health check
- `GET /api/movies?page=1&limit=6&status=To%20Watch&genre=Drama&search=matrix` — list, filter, search and paginate
- `GET /api/movies/next` — highest-priority To Watch movie (shortest runtime breaks ties)
- `GET /api/movies/:id` — get one movie
- `POST /api/movies` — create movie; code is generated server-side
- `PUT /api/movies/:id` — edit allowed fields (title, genre, runtime, platform, priority)
- `PATCH /api/movies/:id/status` — change status; rating required when moving to Watched
- `PATCH /api/movies/:id/rating` — edit rating on Watched movies only
- `DELETE /api/movies/:id` — delete except while Watching
- `GET /api/stats` — status totals, watched hours, average rating, top watched genre

## Rules implemented
- Release year: 1950 through current year. Runtime (30–300 minutes), platform, and priority (1–5) are optional; if supplied, they are validated.
- Movie code: `MV-<year>-<3-digit sequence>`, generated by backend with sequence per year.
- New movies start as `To Watch`.
- Status transitions enforced on backend and reflected in frontend dropdown.
- Rating (1–10) is required when marking Watched; watched date is set automatically. Ratings are allowed/edited only for Watched movies.
- Duplicate title + release year (case-insensitive) returns HTTP 409.
- Six movies per page by default; To Watch movies are prioritized by priority descending.
- Watch Next returns highest priority, then shortest runtime; 404 if none.
- Stats refresh after successful mutations.
- Watching movies cannot be deleted.
- Movie Code and Release Year are not editable.
- Responsive layout for desktop and mobile.
